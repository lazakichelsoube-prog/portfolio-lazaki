Présentation & processus de travail

Développeur Full-Stack / Software Engineer. J'aime transformer des besoins en architectures propres, bien structurées et évolutives.

Je pars toujours du besoin réel avant le code : je clarifie les objectifs, je découpe le problème en modules simples, puis j'avance par itérations courtes et testées.

Développement Backend

Conception d'architectures serveur robustes avec Django et Python : modèles de données, API REST, logique métier et gestion de bases de données.

Développement Frontend

Création d'interfaces claires et réactives avec HTML, CSS et JavaScript (et React), en veillant à l'accessibilité et à l'expérience utilisateur.

Déploiement & mise en ligne

Mise en production d'applications : configuration serveur, gestion des environnements, et suivi une fois le projet en ligne.
